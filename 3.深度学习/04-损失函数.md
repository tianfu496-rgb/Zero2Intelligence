> 训练原理 · 回归、二分类、多分类的训练目标

| 任务   | 损失函数            | 说明                                             |
| :----- | :------------------ | :----------------------------------------------- |
| 回归   | **MSE**             | $`\frac{1}{m}\sum(y_i-\hat{y}_i)^2`$，对大误差敏感 |
| 回归   | MAE / Smooth L1     | 对异常值鲁棒                                     |
| 二分类 | **BCE（二交叉熵）** | $`-[y\log\hat{y}+(1-y)\log(1-\hat{y})]`$           |
| 多分类 | **CE（交叉熵）**    | 配合 Softmax                                     |
