> 架构与复习 · 训练流程和关键公式回顾

| 要点     | 一句话                                                       |
| :------- | :----------------------------------------------------------- |
| 本质     | 多层神经网络自动学特征，数据驱动                             |
| 与ML区别 | DL自动学特征需大数据GPU，ML人工特征小数据CPU                 |
| 核心     | 前向算预测→反向算梯度→优化器更新参数                         |
| 激活函数 | 隐藏层ReLU，二分类Sigmoid，多分类Softmax，大模型GELU         |
| 优化器   | 默认Adam(快)，精调用SGD+Momentum(泛化好)                     |
| 梯度问题 | 消失用ReLU+He+BN+残差，爆炸用梯度裁剪                        |
| 正则化   | CNN用BN+Dropout，Transformer用LN+Dropout                     |
| 架构     | CNN(图像)/RNN(序列)/Transformer(大模型)/ResNet(深网)         |
| 关键公式 | $`z=Wx+b`$，$`a=\sigma(z)`$，$`\theta := \theta - \alpha \nabla L`$ |
