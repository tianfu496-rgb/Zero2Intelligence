> 架构与复习 · CNN、RNN、Transformer、AE 与 GAN

| 架构             | 核心思想                   | 适用场景                         |
| :--------------- | :------------------------- | :------------------------------- |
| **CNN**          | 局部连接 + 权值共享 + 池化 | 图像、视频等网格数据             |
| **RNN/LSTM/GRU** | 隐藏状态传递、门控机制     | 序列数据（文本、时序）           |
| **Transformer**  | 自注意力机制、并行处理     | **现代NLP/大模型基石**(BERT/GPT) |
| **AutoEncoder**  | 编码-解码、瓶颈结构        | 降维、生成、去噪                 |
| **GAN**          | 生成器 vs 判别器对抗       | 图像生成                         |
| **ResNet**       | 残差连接解决深网梯度问题   | 超深CNN（152层+）                |

> **演进脉络**：CNN(图像) → RNN(序列) → Transformer(注意力) → 大模型(预训练)

## 应用场景

- **计算机视觉**：图像分类、目标检测、人脸识别、自动驾驶
- **自然语言处理**：机器翻译、文本生成、情感分析、ChatGPT
- **语音识别**：语音转文字、智能助手
- **推荐系统**：CTR 预估、个性化推荐
- **游戏AI**：AlphaGo、决策智能体
- **科学领域**：蛋白质结构预测、药物发现
