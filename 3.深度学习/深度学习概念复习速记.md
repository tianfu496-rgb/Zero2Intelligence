# 深度学习概念复习速记

## 一、定义与本质

**深度学习 = 深层神经网络 + 自动特征学习**。包含关系：AI ⊃ ML ⊃ 神经网络 ⊃ 深度学习。

| 维度         | 传统机器学习   | 深度学习                   |
| :----------- | :------------- | :------------------------- |
| **隐藏层数** | ≤3 层          | ≥3 层（"深"）              |
| **特征工程** | 人工设计特征   | 自动学习特征               |
| **数据需求** | 少量可用       | 需大量数据                 |
| **硬件依赖** | 低端机器、CPU  | 高端机器、GPU              |
| **训练时间** | 秒~小时        | 小时~天                    |
| **适用数据** | 结构化表格数据 | 非结构化（图像/文本/语音） |
| **输出格式** | 数值/类别      | 文本/图像/音频等           |

## 二、神经网络基础演进

```
生物神经元 → 人工神经元(感知机) → 多层感知机MLP → 深度神经网络DNN
```

- **感知机**：最小可学习单元，$z = w^Tx + b$，只能解决**线性可分**问题
- **MLP（多层感知机）**：输入层 + 隐藏层 + 输出层，全连接，引入非线性解决复杂问题
- **深度神经网络**：隐藏层 ≥2 层，层数越多表达能力越强（底→边缘纹理，中→局部结构，顶→整体判断）

> **关键**：没有激活函数，多层线性网络=单层线性网络；激活函数引入非线性是深度学习能拟合复杂模式的根本

## 三、前向传播与反向传播

| 维度         | 前向传播                  | 反向传播                                                     |
| :----------- | :------------------------ | :----------------------------------------------------------- |
| **方向**     | 输入→输出                 | 输出→输入                                                    |
| **计算**     | $z=Wa+b, a=\sigma(z)$     | $\frac{\partial L}{\partial z}$, $\frac{\partial L}{\partial W}$ |
| **核心机制** | 线性变换+激活函数层层叠加 | **链式法则**逐层回传梯度                                     |
| **作用**     | 算预测值                  | 算各参数梯度供优化器更新                                     |

**训练循环**：前向算预测 → 计算损失 → 反向算梯度 → 优化器更新参数 → 重复

> PyTorch 的 `loss.backward()` 用 autograd 自动完成反向传播，无需手写链式法则

## 四、激活函数对比

| 激活函数       | 公式/特点                               | 优点                            | 缺点                       | 适用场景                      |
| :------------- | :-------------------------------------- | :------------------------------ | :------------------------- | :---------------------------- |
| **Sigmoid**    | $\frac{1}{1+e^{-x}}$，(0,1)             | 适合概率输出                    | 梯度消失、非零中心、计算慢 | 二分类输出层、门控(LSTM/GRU)  |
| **Tanh**       | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$，(-1,1) | 零中心化                        | 仍有梯度消失               | 早期RNN                       |
| **ReLU**       | $\max(0,x)$                             | 计算快、正区间梯度恒为1、稀疏性 | **Dead ReLU**（死神经元）  | **隐藏层默认首选**            |
| **Leaky ReLU** | $\max(\alpha x, x)$                     | 解决死神经元                    | 多一个超参                 | 改进ReLU                      |
| **ELU**        | 负区间逼近零                            | 收敛更快                        | 含指数运算                 | 需快速收敛                    |
| **GELU**       | $x \cdot \Phi(x)$                       | 含随机正则化                    | 计算复杂                   | **Transformer标配**(BERT/GPT) |
| **Softmax**    | 归一化为概率分布                        | 多分类输出                      | —                          | 多分类输出层                  |

> **隐藏层默认 ReLU，二分类输出层 Sigmoid，多分类输出层 Softmax**；现代大模型用 GELU

## 五、常见损失函数

| 任务   | 损失函数            | 说明                                             |
| :----- | :------------------ | :----------------------------------------------- |
| 回归   | **MSE**             | $\frac{1}{m}\sum(y_i-\hat{y}_i)^2$，对大误差敏感 |
| 回归   | MAE / Smooth L1     | 对异常值鲁棒                                     |
| 二分类 | **BCE（二交叉熵）** | $-[y\log\hat{y}+(1-y)\log(1-\hat{y})]$           |
| 多分类 | **CE（交叉熵）**    | 配合 Softmax                                     |

## 六、优化器对比

| 优化器           | 学习率     | 动量       | 收敛速度 | 调参难度 | 泛化     | 适用              |
| :--------------- | :--------- | :--------- | :------- | :------- | :------- | :---------------- |
| **SGD**          | 固定       | 无         | 慢       | 高       | **最好** | 精调、CV          |
| **SGD+Momentum** | 固定       | 有         | 中       | 中       | 好       | 通用              |
| **Adam**         | **自适应** | 有(一阶矩) | 快       | 低       | 中       | **默认首选**、NLP |

**Adam 核心**：结合 Momentum（动量加速）+ RMSprop（自适应学习率）的优点，为每个参数动态调整学习率

> **实践建议**：默认用 Adam，若需更好泛化精调用 SGD+Momentum

## 七、梯度问题

| 问题         | 原因                                                         | 表现                                   | 解决方案                                         |
| :----------- | :----------------------------------------------------------- | :------------------------------------- | :----------------------------------------------- |
| **梯度消失** | 激活函数饱和（Sigmoid导数最大0.25）、网络过深、权重初始化过小 | 浅层参数不更新、训练极慢、深层不如浅层 | ReLU激活、He初始化、BatchNorm、残差连接(ResNet)  |
| **梯度爆炸** | 权重过大、网络过深                                           | Loss=NaN、训练发散                     | 梯度裁剪(Gradient Clipping，RNN必备)、减小学习率 |

> 10层网络用 Sigmoid，梯度连乘 $0.2^{10} ≈ 10^{-7}$，浅层几乎学不到

**现代默认配置**：ReLU/Swish + He初始化 + BatchNorm/LayerNorm + 残差连接/Transformer

## 八、正则化与归一化技术

| 技术               | 作用层面     | 核心机制                             | 适用场景                  |
| :----------------- | :----------- | :----------------------------------- | :------------------------ |
| **L1/L2正则**      | 权重         | 惩罚权重大小                         | 通用、weight_decay        |
| **Dropout**        | 神经元       | 训练时随机失活，打破共适应，等效集成 | 全连接层、NLP/Transformer |
| **BatchNorm (BN)** | 批次维度     | 对每层输入标准化，加速收敛、轻微正则 | CNN、大batch              |
| **LayerNorm (LN)** | 样本特征维度 | 与batch无关，适配变长序列            | **RNN/Transformer标配**   |
| **GroupNorm (GN)** | 通道分组     | 不依赖batch                          | 小batch CV任务            |
| **Early Stopping** | 训练过程     | 验证集不降即停                       | 所有迭代模型              |
| **数据增强**       | 输入数据     | 翻转/裁剪/同义替换                   | 视觉、文本                |

> **关键区分**：BN 依赖 batch_size（<16 会崩），LN 不依赖（Transformer 必备）；CNN 用 BN，Transformer/RNN 用 LN

## 九、经典网络架构

| 架构             | 核心思想                   | 适用场景                         |
| :--------------- | :------------------------- | :------------------------------- |
| **CNN**          | 局部连接 + 权值共享 + 池化 | 图像、视频等网格数据             |
| **RNN/LSTM/GRU** | 隐藏状态传递、门控机制     | 序列数据（文本、时序）           |
| **Transformer**  | 自注意力机制、并行处理     | **现代NLP/大模型基石**(BERT/GPT) |
| **AutoEncoder**  | 编码-解码、瓶颈结构        | 降维、生成、去噪                 |
| **GAN**          | 生成器 vs 判别器对抗       | 图像生成                         |
| **ResNet**       | 残差连接解决深网梯度问题   | 超深CNN（152层+）                |

> **演进脉络**：CNN(图像) → RNN(序列) → Transformer(注意力) → 大模型(预训练)

## 十、应用场景

- **计算机视觉**：图像分类、目标检测、人脸识别、自动驾驶
- **自然语言处理**：机器翻译、文本生成、情感分析、ChatGPT
- **语音识别**：语音转文字、智能助手
- **推荐系统**：CTR 预估、个性化推荐
- **游戏AI**：AlphaGo、决策智能体
- **科学领域**：蛋白质结构预测、药物发现

## 十一、速记口诀

| :------- | :----------------------------------------------------------- |
| 本质     | 多层神经网络自动学特征，数据驱动                             |
| 与ML区别 | DL自动学特征需大数据GPU，ML人工特征小数据CPU                 |
| 核心     | 前向算预测→反向算梯度→优化器更新参数                         |
| 激活函数 | 隐藏层ReLU，二分类Sigmoid，多分类Softmax，大模型GELU         |

| 正则化   | CNN用BN+Dropout，Transformer用LN+Dropout                     |
| 架构     | CNN(图像)/RNN(序列)/Transformer(大模型)/ResNet(深网)         |
| 关键公式 | $z=Wx+b$，$a=\sigma(z)$，$\theta := \theta - \alpha \nabla L$ |
