# 前向传播与反向传播

[仓库首页](../README.md) · [本主题目录](README.md) · [上一篇：激活函数](02-激活函数.md) · [下一篇：损失函数](04-损失函数.md)

> 训练原理 · 计算图、链式法则与参数梯度

| 维度         | 前向传播                  | 反向传播                                                     |
| :----------- | :------------------------ | :----------------------------------------------------------- |
| **方向**     | 输入→输出                 | 输出→输入                                                    |
| **计算**     | $`z=Wa+b, a=\sigma(z)`$     | $`\frac{\partial L}{\partial z}`$, $`\frac{\partial L}{\partial W}`$ |
| **核心机制** | 线性变换+激活函数层层叠加 | **链式法则**逐层回传梯度                                     |
| **作用**     | 算预测值                  | 算各参数梯度供优化器更新                                     |

**训练循环**：前向算预测 → 计算损失 → 反向算梯度 → 优化器更新参数 → 重复

> PyTorch 的 `loss.backward()` 用 autograd 自动完成反向传播，无需手写链式法则
