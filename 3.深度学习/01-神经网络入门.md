> 表达能力 · 感知机、MLP 与深度学习

## 定义与本质

**深度学习 = 深层神经网络 + 自动特征学习**。包含关系：AI ⊃ ML ⊃ 神经网络 ⊃ 深度学习。

| 维度         | 传统机器学习   | 深度学习                   |
| :----------- | :------------- | :------------------------- |
| **隐藏层数** | ≤3 层          | ≥3 层（"深"）              |
| **特征工程** | 人工设计特征   | 自动学习特征               |
| **数据需求** | 少量可用       | 需大量数据                 |
| **硬件依赖** | 低端机器、CPU  | 高端机器、GPU              |
| **训练时间** | 秒~小时        | 小时~天                    |
| **适用数据** | 结构化表格数据 | 非结构化（图像/文本/语音） |
| **输出格式** | 数值/类别      | 文本/图像/音频等           |

## 神经网络基础演进

```
生物神经元 → 人工神经元(感知机) → 多层感知机MLP → 深度神经网络DNN
```

- **感知机**：最小可学习单元，$`z = w^Tx + b`$，只能解决**线性可分**问题
- **MLP（多层感知机）**：输入层 + 隐藏层 + 输出层，全连接，引入非线性解决复杂问题
- **深度神经网络**：隐藏层 ≥2 层，层数越多表达能力越强（底→边缘纹理，中→局部结构，顶→整体判断）

> **关键**：没有激活函数，多层线性网络=单层线性网络；激活函数引入非线性是深度学习能拟合复杂模式的根本
