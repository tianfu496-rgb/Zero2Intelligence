# 自然语言处理（NLP）

> Natural Language Processing，研究如何让计算机理解、生成和处理人类语言。本文按“数据处理 → 序列模型 → Transformer → 预训练与迁移”的主线整理，适合作为入门与复习笔记。

## 第一章 自然语言处理入门

### 1. NLP 是什么

自然语言处理是人工智能、语言学和计算机科学的交叉领域。目标不只是把文字转成数字，还包括理解文本含义、判断上下文关系，以及生成通顺且符合任务要求的语言。

常见任务：

- **文本分类**：情感分析、垃圾邮件识别、新闻分类。
- **序列标注**：中文分词、词性标注（POS）、命名实体识别（NER）。
- **文本匹配**：语义相似度、问答检索、自然语言推理。
- **生成任务**：机器翻译、摘要、对话、续写。
- **信息抽取**：从文本中提取实体、关系、事件和关键信息。

### 2. NLP 的基本流程

```text
原始文本 → 清洗/分词 → 数值化表示 → 模型训练 → 预测与评估 → 部署
```

1. **数据准备**：收集语料，划分训练集、验证集、测试集。
2. **预处理与表示**：将文本切分并转成模型可接受的向量或 token id。
3. **建模**：选择传统机器学习、RNN、Transformer 或预训练模型。
4. **训练与调参**：用训练集最小化损失，在验证集选择超参数。
5. **评估**：在未参与训练和调参的数据上报告指标。

### 3. 常用评价指标

| 任务 | 常用指标 | 含义 |
| --- | --- | --- |
| 分类 | Accuracy、Precision、Recall、F1 | F1 是精确率和召回率的调和平均，类别不均衡时更有意义 |
| 序列标注 | Precision、Recall、实体级 F1 | 同时考虑实体边界和类别是否正确 |
| 生成/翻译 | BLEU、ROUGE、METEOR | 与参考答案的 n-gram 重合度；应结合人工评估 |
| 语言模型 | Perplexity（困惑度） | 越低表示模型对真实文本的预测越确定 |

$F1=\frac{2PR}{P+R}$，其中 $P$ 为 Precision，$R$ 为 Recall。

## 第二章 文本预处理

### 1. 认识文本预处理

文本是非结构化数据，必须在进入模型前进行规范化和切分。预处理不应机械套用：例如情感分析中的感叹号、否定词、表情符号常含有重要信息，不能随意删除。

常见步骤：

- 去除或统一无意义字符、异常空白、HTML 标签。
- 英文常进行大小写统一、词形还原（lemmatization）或词干提取（stemming）。
- 中文常需分词；中文 BERT 类模型通常使用字或子词切分。
- 构建词表（vocabulary），设置 `<PAD>`、`<UNK>`、`<BOS>`、`<EOS>` 等特殊符号。
- 将不同长度序列截断或补齐，并记录有效长度或 attention mask。

### 2. 文本处理的基本方法

#### 分词（Tokenization）

分词是将文本拆成模型处理的最小单元。英文空格可以提供部分边界，中文则需要额外策略。

- **基于词典**：正向/逆向最大匹配，速度快但难处理未登录词。
- **基于统计模型**：如 HMM、CRF，能结合上下文做分词或标注。
- **子词分词**：BPE、WordPiece、Unigram。高频词保持完整，罕见词拆成子词，兼顾词表规模和未知词处理能力。

以 BERT 的 WordPiece 为例，`playing` 可能切分为 `play` 与 `##ing`；`##` 表示它不是一个词的开头。

#### 停用词与规范化

停用词（如“的”“了”“the”）在词袋模型中有时会被移除以降噪；但在 Transformer、问答、翻译等依赖语序和语法的任务中，通常**不建议**删除。数字、日期、网址可按任务需求保留、归一化或替换为占位符。

#### Padding、截断与 Mask

一个 batch 的张量必须具有相同长度。短序列使用 `<PAD>` 补齐，长序列按最大长度截断。训练时应使用 mask，使补齐位置不参与注意力计算和损失计算。

### 3. 文本张量表示方法

#### One-hot 编码

若词表大小为 $V$，每个词用一个长度为 $V$ 的向量表示，所在词表位置为 1，其余为 0。

- 优点：直观、无需训练。
- 缺点：维度高、极度稀疏；任意两个不同词的向量距离相同，无法表达语义相似性。

#### Bag of Words 与 TF-IDF

**词袋模型（BoW）**只统计词是否出现或出现次数，不保留顺序。

TF-IDF 用词频与逆文档频率衡量词的重要性：

$$
TF\text{-}IDF(w,d)=TF(w,d)\times \log\frac{N}{DF(w)+1}
$$

它适合传统文本分类和检索，但仍忽略词序与上下文。

#### Word2Vec

Word2Vec 学习稠密的词向量，使上下文相似的词在向量空间中更接近。

- **CBOW**：根据上下文预测中心词，训练速度快，适合高频词。
- **Skip-gram**：根据中心词预测周围词，对低频词效果通常更好。

经典现象：`vec(国王) - vec(男人) + vec(女人)` 的近邻往往是“女王”。这说明向量能捕捉部分语义关系，但不代表它真正理解世界知识。

#### Word Embedding

Embedding 本质是一个可学习的查表矩阵 $E\in\mathbb{R}^{V\times d}$。输入 token id 后直接取第 id 行作为 $d$ 维稠密向量。它是深度 NLP 模型的基础层，可随机初始化后随任务训练，也可加载预训练词向量。

**静态词向量的局限**：同一词只有一个向量，无法区分多义词。例如“苹果手机”和“苹果水果”中的“苹果”语义不同。ELMo、BERT 等上下文词向量解决了这一问题。

### 4. 文本数据分析

在训练前先做 EDA（探索性数据分析），常能发现数据质量问题：

- 类别数量是否失衡，是否需要重采样、类别权重或 F1 指标。
- 文本长度分布，用于设定合理的最大长度。
- 高频词、低频词与未登录词比例，决定词表和分词方案。
- 标签是否存在重复、噪声、泄漏或标注标准不一致。
- 训练、验证、测试集的领域和标签分布是否一致。

数据泄漏是常见陷阱：例如同一用户的近似文本同时出现在训练集和测试集，会使离线分数虚高。

### 5. 文本数据增强

文本增强的目标是增加样本多样性和鲁棒性，同时必须确保标签不被改变。

- **同义词替换**：替换非关键词；需防止替换后语义或情感倾向变化。
- **随机插入/删除/交换**：适合轻度扰动，不宜过强。
- **回译**：中文 → 英文 → 中文，以不同表达保留大致语义。
- **掩码语言模型增强**：用预训练模型替换部分词。
- **对抗训练**：在 embedding 上添加微小扰动，提高模型稳定性。

## 第三章 RNN 及其变体

### 1. 认识 RNN 模型

循环神经网络（RNN）适用于序列数据。它按时间步读取输入，并将历史信息存入隐藏状态 $h_t$：

$$
h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h)
$$

其中 $x_t$ 是当前输入，$h_{t-1}$ 是前一时刻状态。RNN 的参数在各时间步共享，理论上能处理任意长度序列。

### 2. 传统 RNN 模型

RNN 可构成多种输入输出结构：

- **one-to-many**：图像描述生成。
- **many-to-one**：句子情感分类。
- **many-to-many（等长）**：词性标注。
- **many-to-many（非等长）**：机器翻译，通常使用 Seq2Seq。

#### 梯度消失与梯度爆炸

RNN 通过时间反向传播（BPTT）训练。长序列中梯度会连续乘以权重矩阵：若范数长期小于 1，梯度趋近于 0；若大于 1，则可能爆炸。因此传统 RNN 难以记住长期依赖。

常见缓解方法：梯度裁剪、合理初始化、使用 LSTM/GRU、缩短序列或采用注意力机制。

### 3. LSTM 模型

长短期记忆网络（LSTM）通过细胞状态 $c_t$ 和门控机制控制信息流。

- **遗忘门** $f_t$：保留多少旧记忆。
- **输入门** $i_t$：写入多少当前候选信息。
- **输出门** $o_t$：从细胞状态输出多少信息。

核心更新：

$$
c_t=f_t\odot c_{t-1}+i_t\odot \tilde{c}_t
$$

$$
h_t=o_t\odot \tanh(c_t)
$$

门值在 0 到 1 之间，使用逐元素乘法调节信息。LSTM 的加性细胞状态路径有利于梯度传播，因此比普通 RNN 更能处理长依赖。

### 4. GRU 模型

门控循环单元（GRU）是 LSTM 的简化版本：将遗忘门与输入门的作用整合为**更新门**，另有**重置门**决定忽略多少历史信息。

- 参数比 LSTM 少，训练和推理通常更快。
- 没有独立的细胞状态，隐藏状态同时承担记忆功能。
- 在很多任务上效果与 LSTM 接近；数据量较小或计算资源有限时常是不错的选择。

### 5. RNN 案例：全球人名分类任务

**任务**：根据姓名拼写预测其语言/国籍类别，例如 English、Chinese、Italian。

典型流程：

1. 将姓名按字符切分，建立字符词表。
2. 每个字符转为 one-hot 或 embedding 向量。
3. 用 RNN/LSTM/GRU 按字符读取，取最后隐藏状态作为姓名表示。
4. 接全连接层和 softmax 输出类别概率。
5. 使用交叉熵损失训练，以 Accuracy、混淆矩阵观察结果。

该案例适合理解“序列输入 → 最终分类”的 many-to-one 结构。注意：名字与国籍只能反映训练数据中的统计关联，不能用于对个体做可靠判断。

### 6. 注意力机制介绍

Seq2Seq 的早期做法把整个源句压缩进一个固定长度向量，长句会形成信息瓶颈。注意力机制让解码器在生成每个词时，动态查看全部编码器状态。

对解码第 $t$ 步，计算当前解码状态 $s_{t-1}$ 与每个编码状态 $h_i$ 的匹配分数：

$$
\alpha_{t,i}=\text{softmax}(score(s_{t-1},h_i))
$$

$$
c_t=\sum_i\alpha_{t,i}h_i
$$

$\alpha_{t,i}$ 是注意力权重，$c_t$ 是上下文向量。它能学习软对齐关系，例如翻译某个法语词时更关注对应的英语词。

### 7. RNN 案例：Seq2Seq 英译法

Seq2Seq 通常由编码器和解码器组成：

```text
English tokens → Encoder RNN → encoder states
                                  ↓
<BOS> → Decoder RNN → French tokens → <EOS>
```

- **编码器**：读取源语言序列，产生隐藏状态。
- **解码器**：从 `<BOS>` 开始，逐词预测目标语言 token。
- **训练阶段**：常用 Teacher Forcing，即输入真实的上一个目标词。
- **推理阶段**：输入模型上一步自己预测的词，直到生成 `<EOS>` 或到达长度上限。
- **解码策略**：贪心搜索简单但容易局部最优；Beam Search 保留多个候选，通常能改善翻译质量。

训练与推理的不一致会导致 exposure bias：训练时模型总见到真实历史，推理时却要面对自己的错误历史。

### 8. 注意力机制扩展阅读

- **加性注意力（Bahdanau Attention）**：用小型前馈网络计算匹配分数。
- **点积注意力（Luong / Dot-product）**：用向量点积计算，速度较快。
- **自注意力（Self-Attention）**：同一序列内部的每个 token 都关注其他 token，是 Transformer 的核心。
- **交叉注意力（Cross-Attention）**：一个序列的 Query 关注另一个序列的 Key、Value，常用于编码器—解码器结构。

注意力权重有一定可解释性，但不能简单等同于因果解释或模型真实“理由”。

## 第四章 Transformer

### 1. Transformer 的背景介绍

Transformer 出自 2017 年论文 *Attention Is All You Need*。它抛弃循环结构，主要依赖注意力机制建模全局关系。

相对 RNN 的优势：

- 同一层中可并行处理所有 token，训练效率高。
- 任意两个位置之间的信息交互路径更短，擅长长距离依赖。
- 易于扩展为大规模预训练模型，如 BERT、GPT、T5。

局限是标准自注意力的时间和空间复杂度随序列长度呈 $O(n^2)$ 增长，超长文本成本较高。

### 2. 认识 Transformer 的架构

原始 Transformer 是 encoder-decoder 架构：

```text
输入嵌入 + 位置编码
        ↓
Encoder × N ────────────────┐
                              ↓
目标词嵌入 + 位置编码 → Decoder × N → Linear + Softmax
```

- **Encoder**：由多头自注意力、前馈网络、残差连接、层归一化组成，适合“理解”类任务。
- **Decoder**：在此基础上多了编码器—解码器注意力，并对自身未来位置使用 causal mask，适合自回归生成。
- **Encoder-only**：如 BERT，双向理解文本。
- **Decoder-only**：如 GPT，按从左到右预测下一个 token。

### 3. 细节原理解析

#### 输入部分：Token Embedding 与位置编码

自注意力本身不包含顺序信息，因此输入表示为：

$$
X=TokenEmbedding+PositionalEncoding
$$

原始论文使用正弦/余弦位置编码；现代模型也常使用可学习位置编码、RoPE（旋转位置编码）等方案。

#### 自注意力机制

输入 $X$ 分别线性映射得到 Query、Key、Value：

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V
$$

缩放点积注意力为：

$$
Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}}+M)V
$$

其中 $M$ 是 mask：padding mask 屏蔽补齐 token；causal mask 屏蔽未来 token。除以 $\sqrt{d_k}$ 可防止维度较大时点积过大，导致 softmax 梯度过小。

#### 多头注意力（Multi-Head Attention）

多头注意力在多个子空间并行计算注意力，再拼接投影：

$$
MultiHead=Concat(head_1,...,head_h)W_O
$$

不同的头可学习不同类型的关系，如局部搭配、指代、句法关联等。

#### 编码器层

一个 Encoder Layer：

```text
输入 → Multi-Head Self-Attention → Add & Norm → Feed Forward → Add & Norm
```

前馈网络（FFN）对每个位置独立、共享参数地进行非线性变换，通常维度先扩大再压回。残差连接帮助深层训练，LayerNorm 稳定激活分布。

#### 解码器层

Decoder Layer 包含三部分：

1. **Masked Self-Attention**：每个位置只能看见当前及之前 token。
2. **Cross-Attention**：Query 来自解码器，Key/Value 来自编码器输出。
3. **FFN**：逐位置非线性变换。

最后通过线性层映射到词表大小，再以 softmax 得到下一个 token 的概率分布。

### 4. Transformer 的构建过程

实现时的关键检查点：

1. 定义 tokenizer、词表、`<PAD>/<BOS>/<EOS>` 与 batch mask。
2. 实现 token embedding 与位置编码，并确保维度为 `[batch, seq_len, d_model]`。
3. 实现 scaled dot-product attention，正确处理 padding 和 causal mask。
4. 叠加多头注意力、FFN、残差连接、LayerNorm，组成编码器/解码器层。
5. 使用交叉熵训练。对 `<PAD>` 位置设置 `ignore_index`，避免其影响损失。
6. 推理时从 `<BOS>` 自回归生成；可使用贪心、beam search、top-k、top-p、temperature 等策略。

常见错误：mask 方向写反、忘记在 attention score 上加 mask、将 padding 计入损失、位置编码与 embedding 维度不匹配。

### 5. 案例：构建基于 Transformer 的语言模型

语言模型学习条件概率：

$$
P(x_1,...,x_T)=\prod_{t=1}^{T}P(x_t\mid x_{<t})
$$

训练目标是预测下一个 token。给定 `我 喜欢 学习`，模型输入可为 `我 喜欢 学习`，监督标签右移一位：`喜欢 学习 <EOS>`。

- 使用 decoder-only Transformer 和 causal mask，避免模型在训练时偷看未来答案。
- 损失函数通常是 token 级交叉熵。
- 温度 $T$ 越低，分布越集中；越高，文本更多样但更容易失控。
- top-k 从概率最高的 k 个 token 中采样；top-p（nucleus sampling）从累计概率达到 p 的候选集中采样。

## 第五章 迁移学习

### 1. FastText 工具介绍

FastText 是 Meta 开源的高效文本表示与分类工具。它的特点是将词表示为字符 n-gram 的组合，因此对未登录词、拼写变化和形态丰富语言更友好。

与 Word2Vec 相比，FastText 不只学习整词向量，也学习子词向量。例如 `where` 可由 `<wh`、`whe`、`her`、`ere`、`re>` 等 n-gram 共同表示。

### 2. FastText 文本分类

FastText 分类通常采用“词向量平均 + 线性分类器”的轻量结构，并使用层次 softmax 或负采样提升大类别场景的效率。

训练数据常用一行一个样本的格式：

```text
__label__positive 这个产品很好用
__label__negative 物流太慢了
```

优点是训练快、部署轻量，适合基线模型和资源受限场景；缺点是对复杂语序和深层语义的表达弱于 Transformer。

### 3. 训练词向量

训练词向量的通用步骤：

1. 准备足够大、领域匹配的无标注语料。
2. 选择分词方式、维度、窗口大小、最小词频等超参数。
3. 用 Word2Vec、GloVe 或 FastText 训练。
4. 通过相似词、词类比、下游任务效果进行评估。

领域词（医疗、法律、金融、代码等）往往与通用语料差异很大，此时在领域语料上继续训练或重新训练词向量通常更有价值。

### 4. 词向量迁移

迁移词向量是将通用语料训练出的 embedding 用于下游任务：

- **冻结**：预训练 embedding 固定，只训练任务模型。数据少时更稳定。
- **微调**：embedding 与任务模型一起更新。适应性更强，但数据少时可能破坏原有语义结构。
- **部分冻结**：高频词或底层固定，其余可训练，作为折中方案。

迁移前需确认 tokenizer 和词表映射一致；否则即使向量文件正确，词与行号错位也会导致模型失效。

### 5. 迁移学习概念

迁移学习是把源任务/源领域学到的知识迁移到目标任务，以减少目标任务的数据和训练成本。

```text
大规模无标注语料预训练 → 小规模有标注下游任务微调
```

常见方式：

- **Feature-based**：将预训练模型输出作为固定特征。
- **Fine-tuning**：加载预训练参数，在下游数据上继续训练。
- **Prompt / In-context Learning**：通过指令、示例或提示词激发模型能力，少量甚至无需更新参数。
- **PEFT**：参数高效微调，如 Adapter、LoRA、Prefix Tuning，只训练很少一部分参数。

### 6. NLP 中常用的预训练模型

| 模型 | 架构 | 预训练目标 | 典型特点 |
| --- | --- | --- | --- |
| ELMo | 双向 LSTM | 双向语言模型 | 产生上下文相关词向量 |
| GPT 系列 | Decoder-only | 因果语言模型（预测下一个词） | 擅长生成、续写、对话 |
| BERT | Encoder-only | MLM + 原始版本的 NSP | 双向上下文建模，擅长理解任务 |
| RoBERTa | Encoder-only | 改进的 MLM 训练 | 移除 NSP、更多数据和更充分训练 |
| T5 / BART | Encoder-Decoder | 去噪/文本到文本 | 适合翻译、摘要等生成任务 |

### 7. Transformers 库的使用

Hugging Face Transformers 提供 tokenizer、预训练权重、训练工具和推理 pipeline。典型步骤：

1. 根据任务选择合适的 checkpoint 与模型头，例如分类用 `AutoModelForSequenceClassification`。
2. 用对应 tokenizer 将文本编码为 `input_ids`、`attention_mask` 等张量。
3. 加载预训练模型，在任务数据上训练或直接推理。
4. 保存模型、tokenizer 与配置；部署时三者应保持对应。

关键原则：**模型和 tokenizer 必须来自同一个 checkpoint 或兼容版本**。中文任务还应关注简体/繁体、领域语料以及最大序列长度。

## 第六章 NLP 精选问答

### 1. Transformer 常见问答

#### Q1：为什么 Transformer 需要位置编码？

自注意力对输入 token 的排列本身不敏感。如果没有位置编码，“我喜欢你”和“你喜欢我”会得到相同的词集合信息。位置编码将顺序注入 token 表示。

#### Q2：Self-Attention 的 Q、K、V 分别是什么？

可以把 Query 理解为“我正在寻找什么”，Key 理解为“我能提供什么线索”，Value 是“被选中后传递的内容”。Q 与 K 的相似度决定对 V 的加权方式。

#### Q3：为什么使用多头注意力？

单个注意力头只能在一个表示子空间中建立关系；多头机制让模型从多个角度同时关注序列，再融合结果，表达能力更强。

#### Q4：Transformer 和 RNN 的主要区别？

RNN 按顺序递归计算，天然有顺序信息但难并行、长依赖路径长；Transformer 用位置编码表示顺序，能并行计算且任意位置直接交互，但标准注意力对长序列开销大。

#### Q5：LayerNorm 与 BatchNorm 为什么不同？

BatchNorm 依赖 batch 维统计量，在变长序列和小 batch 中不方便；LayerNorm 对每个样本的特征维度归一化，不依赖 batch 大小，因此更适合 Transformer。

### 2. BERT 模型特点

BERT（Bidirectional Encoder Representations from Transformers）使用 Transformer Encoder，通过双向上下文生成 token 表示。

- **Masked Language Model（MLM）**：随机遮住部分 token，让模型预测它们，从左右两侧学习上下文。
- **Next Sentence Prediction（NSP）**：原始 BERT 用于学习句对关系；后续研究表明它并非总是必要。
- **特殊 token**：`[CLS]` 常作为分类汇总表示，`[SEP]` 分隔句子，`[MASK]` 用于 MLM。
- **微调方式**：在 `[CLS]` 输出上加分类层可做分类；使用每个 token 输出可做 NER、抽取式问答等。

BERT 并非天然适合从左到右自由生成：MLM 训练方式与自回归生成不完全一致，生成一般更常使用 GPT/T5/BART 类模型。

### 3. ELMo 模型的介绍

ELMo（Embeddings from Language Models）基于双向 LSTM 语言模型，将不同层的隐藏状态加权组合，得到随上下文变化的词向量。

它的重要贡献是证明了**上下文相关表示**的价值：同一个词在不同句子中的向量可以不同。与 BERT 相比，ELMo 使用 LSTM，双向信息通常由两个单向语言模型分别得到；BERT 则通过 Transformer 的 MLM 更深度地融合双向上下文。

### 4. GPT 模型介绍

GPT（Generative Pre-trained Transformer）采用 decoder-only Transformer，以因果语言模型目标训练：只能根据前文预测下一个 token。

- **预训练**：在海量文本上学习语言规律和世界知识的统计模式。
- **适配**：可通过提示词、上下文示例、监督微调、偏好对齐或 LoRA 等方式适配任务。
- **生成**：逐 token 自回归输出，适合对话、写作、代码生成、摘要等。
- **局限**：可能产生幻觉、继承训练数据偏差、对提示敏感；高风险场景需结合检索、工具调用、约束与人工审核。

### 5. 高频概念速记

| 概念 | 一句话记忆 |
| --- | --- |
| Token | 模型处理文本的基本单位，可以是字、词或子词 |
| Embedding | 将离散 token 映射为稠密连续向量 |
| Mask | 屏蔽不应参与计算的位置，如 PAD 或未来 token |
| Teacher Forcing | 训练生成模型时喂给真实上一个词 |
| Fine-tuning | 用下游数据继续训练预训练模型 |
| Hallucination | 模型生成看似合理但不真实或无依据的内容 |
| RAG | 在生成前检索外部资料，以补充可追溯上下文 |

## 复习路线建议

1. 先掌握 tokenization、one-hot、embedding、TF-IDF 等输入表示。
2. 理解 RNN 的隐藏状态、梯度问题，以及 LSTM/GRU 的门控思想。
3. 重点吃透注意力公式、Q/K/V、mask、多头注意力和位置编码。
4. 区分 BERT（理解）、GPT（生成）、T5/BART（编码器—解码器生成）的架构与适用任务。
5. 通过文本分类、NER、翻译或小型语言模型项目把完整流程实践一遍。
