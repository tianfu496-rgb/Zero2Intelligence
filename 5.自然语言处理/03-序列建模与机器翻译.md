## 循环序列模型

### 认识 RNN 模型

循环神经网络（RNN）适用于序列数据。它按时间步读取输入，并将历史信息存入隐藏状态 $`h_t`$：

```math
h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h)
```

其中 $`x_t`$ 是当前输入，$`h_{t-1}`$ 是前一时刻状态。RNN 的参数在各时间步共享，理论上能处理任意长度序列。

### 传统 RNN 模型

RNN 可构成多种输入输出结构：

- **one-to-many**：图像描述生成。
- **many-to-one**：句子情感分类。
- **many-to-many（等长）**：词性标注。
- **many-to-many（非等长）**：机器翻译，通常使用 Seq2Seq。

#### 梯度消失与梯度爆炸

RNN 通过时间反向传播（BPTT）训练。长序列中梯度会连续乘以权重矩阵：若范数长期小于 1，梯度趋近于 0；若大于 1，则可能爆炸。因此传统 RNN 难以记住长期依赖。

常见缓解方法：梯度裁剪、合理初始化、使用 LSTM/GRU、缩短序列或采用注意力机制。

### LSTM 模型

长短期记忆网络（LSTM）通过细胞状态 $`c_t`$ 和门控机制控制信息流。

- **遗忘门** $`f_t`$：保留多少旧记忆。
- **输入门** $`i_t`$：写入多少当前候选信息。
- **输出门** $`o_t`$：从细胞状态输出多少信息。

核心更新：

```math
c_t=f_t\odot c_{t-1}+i_t\odot \tilde{c}_t
```

```math
h_t=o_t\odot \tanh(c_t)
```

门值在 0 到 1 之间，使用逐元素乘法调节信息。LSTM 的加性细胞状态路径有利于梯度传播，因此比普通 RNN 更能处理长依赖。

### GRU 模型

门控循环单元（GRU）是 LSTM 的简化版本：将遗忘门与输入门的作用整合为**更新门**，另有**重置门**决定忽略多少历史信息。

- 参数比 LSTM 少，训练和推理通常更快。
- 没有独立的细胞状态，隐藏状态同时承担记忆功能。
- 在很多任务上效果与 LSTM 接近；数据量较小或计算资源有限时常是不错的选择。

## 序列分类与机器翻译案例

### RNN 案例：全球人名分类任务

**任务**：根据姓名拼写预测其语言/国籍类别，例如 English、Chinese、Italian。

典型流程：

1. 将姓名按字符切分，建立字符词表。
2. 每个字符转为 one-hot 或 embedding 向量。
3. 用 RNN/LSTM/GRU 按字符读取，取最后隐藏状态作为姓名表示。
4. 接全连接层和 softmax 输出类别概率。
5. 使用交叉熵损失训练，以 Accuracy、混淆矩阵观察结果。

该案例适合理解“序列输入 → 最终分类”的 many-to-one 结构。注意：名字与国籍只能反映训练数据中的统计关联，不能用于对个体做可靠判断。

### RNN 案例：Seq2Seq 英译法

Seq2Seq 通常由编码器和解码器组成：

```text
English tokens → Encoder RNN → encoder states
                                  ↓
<BOS> → Decoder RNN → French tokens → <EOS>
```

- **编码器**：读取源语言序列，产生隐藏状态。
- **解码器**：从 `<BOS>` 开始，逐词预测目标语言 token。
- **训练阶段**：常用 Teacher Forcing，即输入真实的上一个目标词。
- **推理阶段**：输入模型上一步自己预测的词，直到生成 `<EOS>` 或到达长度上限。
- **解码策略**：贪心搜索简单但容易局部最优；Beam Search 保留多个候选，通常能改善翻译质量。

训练与推理的不一致会导致 exposure bias：训练时模型总见到真实历史，推理时却要面对自己的错误历史。
