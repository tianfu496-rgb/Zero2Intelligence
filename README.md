## 阅读与编辑约定

- 每篇笔记使用一个一级标题；章节依次使用二级、三级标题。
- 行内公式使用 `$...$`，独立公式使用单独成行的 `$$...$$`。
- 在表格公式中，用 `\lvert` / `\rvert` 或 `\mid` 表示竖线，避免竖线被识别为表格分隔符。
- 代码示例使用带语言名的围栏代码块。编辑后请在 GitHub 页面检查标题、表格和公式的显示效果。
