# 随机森林 Random Forest

> 集成方法 · Bootstrap、随机特征、投票与袋外估计


## 从决策树到森林

单棵深树容易随训练样本变化。随机森林训练多棵树，再把预测聚合。它通过两种随机性降低树之间的相关性：对样本做有放回抽样，并在每次节点分裂时只考虑部分特征。

## 训练与预测

1. 对训练集 Bootstrap 抽样，得到每棵树的训练子集。
2. 每个节点随机选择一部分特征，再寻找分裂。
3. 分类时聚合各树的类别概率；回归时平均各树的数值预测。

回归聚合公式：

$$
\hat y(x)=\frac1B\sum_{b=1}^{B}T_b(x)
$$

如果每棵树预测的方差均为 $`\sigma^2`$，两两相关系数近似为 $`\rho`$，则平均预测的方差为：

$$
\operatorname{Var}(\bar T)=\rho\sigma^2+\frac{1-\rho}{B}\sigma^2
$$

增加树的数量可以降低后一项；让树更不相似可以降低相关性带来的限制。

## 参数与评估

| 参数 | 作用 |
| --- | --- |
| `n_estimators` | 树的数量，影响计算成本和聚合稳定性 |
| `max_features` | 每次分裂考虑的特征数量，调节多样性 |
| `max_depth` / `min_samples_leaf` | 控制单棵树的复杂度 |
| `bootstrap` / `oob_score` | Bootstrap 抽样与袋外误差估计 |

某棵树未抽到的样本可以参与该树的袋外评估。OOB 有助于估计泛化表现；最终测试集仍应用于独立评估。随机森林也会过拟合，不能把“多棵树”理解为不需要验证。

## 初始化示例


```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(
    n_estimators=100,      # 树的数量
    max_features='sqrt',   # 每次分裂考虑的特征数（经验值）
    max_depth=None,        # 可通过树深、叶子样本数控制复杂度
    n_jobs=-1,             # 并行训练
    oob_score=True,        # 袋外误差估计，仍需独立测试集
    random_state=42
)
```


后续使用已划分的 `X_train, y_train` 调用 `rf.fit(...)`，在测试集上计算指标。树模型通常无需特征标准化，但仍需妥善处理缺失值、类别编码和数据泄漏。

参考：[scikit-learn 随机森林与集成学习](https://scikit-learn.org/stable/modules/ensemble.html#forests-of-randomized-trees)。
