## 图像滤波

| 方法      | 类型     | 主要作用   |
| --------- | -------- | ---------- |
| Mean      | 低通     | 平滑       |
| Gaussian  | 低通     | 平滑、去噪 |
| Median    | 非线性   | 去椒盐噪声 |
| Sobel     | 一阶导数 | 边缘       |
| Prewitt   | 一阶导数 | 边缘       |
| Laplacian | 二阶导数 | 边缘/细节  |
| Canny     | 综合     | 边缘检测   |

---

## 特征

| 方法   | 检测     | 描述 | 特点            |
| ------ | -------- | ---- | --------------- |
| Harris | Corner   | ❌    | 角点检测        |
| SIFT   | Keypoint | ✓    | 尺度、旋转鲁棒  |
| SURF   | Keypoint | ✓    | SIFT 的快速思想 |
| ORB    | Keypoint | ✓    | 快、二进制      |

---

## 分割

| 方法                  | 类型        | 核心         |
| --------------------- | ----------- | ------------ |
| Threshold             | 无监督/规则 | 像素阈值     |
| Otsu                  | 自动阈值    | 最大类间方差 |
| Region Growing        | 区域        | 邻域相似性   |
| K-means               | 聚类        | 距离         |
| Watershed             | 区域        | 地形/分水岭  |
| Semantic Segmentation | 深度学习    | 像素类别     |
| Instance Segmentation | 深度学习    | 像素 + 实例  |

---

## 几何视觉

| 概念               | 作用                          |
| ------------------ | ----------------------------- |
| Camera Model       | 3D → 2D                       |
| Intrinsic          | 相机内部参数                  |
| Extrinsic          | 世界 → 相机                   |
| Homography         | 两平面/纯旋转情况下的投影关系 |
| Fundamental Matrix | 极几何                        |
| Essential Matrix   | 归一化坐标下的极几何          |
| Stereo             | 双目深度                      |
| Triangulation      | 从多视图恢复 3D               |

---

## 检测模型

| 模型         | 类型      | 核心                  |
| ------------ | --------- | --------------------- |
| R-CNN        | Two-stage | Region Proposal + CNN |
| Fast R-CNN   | Two-stage | 共享 CNN              |
| Faster R-CNN | Two-stage | RPN                   |
| YOLO         | One-stage | 直接预测              |
| SSD          | One-stage | 多尺度预测            |

---

## CNN 网络

| 网络      | 核心思想               |
| --------- | ---------------------- |
| LeNet     | 经典早期 CNN           |
| AlexNet   | ReLU + GPU + 深度 CNN  |
| VGG       | 深层 + $`3\times3`$ Conv |
| GoogLeNet | Inception              |
| ResNet    | Residual               |
| DenseNet  | Dense Connection       |
| ViT       | Transformer + Patch    |
