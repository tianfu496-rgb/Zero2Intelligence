## 分类任务与学习路线

图像分类回答“整幅图像属于什么类别”。先区分单标签、多标签和开放词表设置，再选择输出层、训练目标与评价方式。分类器通常由视觉编码器和任务头组成；预训练编码器也可通过冻结特征、线性探测或微调用于分类。

```text
图像 → 视觉编码器 → 全局表示 → 分类头或图文相似度 → 类别与置信度
```

单标签分类可使用交叉熵；多标签分类通常为每个标签独立建模。报告 Accuracy、每类召回率或 F1 时，还应检查类别不平衡和划分方式。

## CNN 的基本组件与训练

### CNN

CNN：

> Convolutional Neural Network

核心结构：

```text
Input
 ↓
Convolution
 ↓
Activation
 ↓
Pooling
 ↓
Convolution
 ↓
...
 ↓
Fully Connected / Classification Head
```

CNN 擅长处理：

> **具有空间结构的数据。**

### 卷积层

卷积核：

```math
K\in\mathbb{R}^{H\times W\times C}
```

卷积的核心：

> **局部连接 + 权重共享。**

优点：

- 参数量减少
- 可以提取局部特征
- 保留空间结构

---

#### 参数量

Kernel：

```math
K\times K
```

输入通道：

CinC_{in}

输出通道：

CoutC_{out}

参数量：

K2CinCoutK^2C_{in}C_{out}

如果有 Bias：

K2CinCout+CoutK^2C_{in}C_{out}+C_{out}

### Padding / Stride

输出尺寸：

```math
O=\left\lfloor\frac{N+2P-K}{S}\right\rfloor+1
```

其中：

- $`N`$：输入尺寸
- $`P`$：Padding
- $`K`$：Kernel
- $`S`$：Stride

### Pooling

#### Max Pooling

取窗口最大值。

```text
1  3
2  4

→ 4
```

#### Average Pooling

取平均值。

作用：

- 降低空间尺寸
- 减少计算
- 提高一定程度的平移鲁棒性
- 扩大感受野

PyTorch：

```python
import torch.nn as nn

pool = nn.MaxPool2d(
    kernel_size=2,
    stride=2
)
```

### ReLU

```math
\mathrm{ReLU}(x)=\max(0,x)
```

```python
relu = nn.ReLU()
```

优点：

- 简单
- 计算快
- 缓解部分梯度消失问题

缺点：

> 负数区域梯度为 0，可能出现 Dead ReLU。

### Fully Connected Layer

全连接层：

```math
y=Wx+b
```

每个输出神经元连接所有输入。

通常 CNN 最后可以：

```text
Feature Map
 ↓
Flatten / Global Pooling
 ↓
Fully Connected
 ↓
Class Scores
```

### Batch Normalization

对于一个 Batch：

```math
\hat{x}=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}
```

然后：

```math
y=\gamma\hat{x}+\beta
```

其中：

- $`\gamma`$：可学习缩放
- $`\beta`$：可学习偏移

作用：

- 稳定训练
- 加快收敛
- 一定程度上减少过拟合

PyTorch：

```python
bn = nn.BatchNorm2d(64)
```

### Dropout

训练时随机将部分神经元置零。

```python
dropout = nn.Dropout(p=0.5)
```

作用：

> **减少过拟合。**

注意：

> Dropout 通常只在训练阶段启用。

### Backpropagation

神经网络训练：

```text
Input
 ↓
Forward
 ↓
Prediction
 ↓
Loss
 ↓
Backward
 ↓
Gradient
 ↓
Optimizer
 ↓
Parameter Update
```

梯度下降：

```math
\theta_{t+1}=\theta_t-\eta\nabla_\theta L
```

其中：

- $`\theta`$：参数
- $`\eta`$：Learning Rate
- $`L`$：Loss

---

#### PyTorch 示例

```python
optimizer.zero_grad()

output = model(x)

loss = criterion(output, y)

loss.backward()

optimizer.step()
```

### Loss Function

#### MSE

常用于回归：

```math
L=\frac1N\sum_i(y_i-\hat y_i)^2
```

---

#### Cross Entropy

分类任务常用：

```math
L=-\sum_i y_i\log p_i
```

如果真实类别是 $`k`$：

```math
L=-\log p_k
```

因此：

> 真实类别预测概率越高 → Loss 越小。

PyTorch：

```python
criterion = nn.CrossEntropyLoss()

loss = criterion(
    prediction,
    label
)
```

## 经典 CNN 架构

### LeNet

LeNet 是早期经典 CNN。

基本结构：

```text
Input
 ↓
Conv
 ↓
Pooling
 ↓
Conv
 ↓
Pooling
 ↓
FC
 ↓
Output
```

主要用于：

> 手写数字识别。

意义：

> 证明 CNN 对图像识别非常有效。

### AlexNet

AlexNet 在 ImageNet 竞赛中取得重要突破。

特点：

- 更深的 CNN
- ReLU
- Dropout
- GPU 训练
- Data Augmentation

核心贡献：

> 推动深度 CNN 在大规模图像分类中的应用。

### VGG

VGG 的核心思想：

> **使用大量 $`3\times3`$ 小卷积核构建深层网络。**

典型：

- VGG-16
- VGG-19

特点：

- 结构简单
- 网络较深
- 参数量较大

### GoogLeNet / Inception

核心：

> **Inception Module**

同时使用不同大小卷积：

```text
        Input
       /  |  \
     1x1 3x3 5x5
       \  |  /
        Concat
```

优点：

> 同时捕获不同尺度的信息。

另外使用 $`1\times1`$ Conv：

> **降低通道数、减少计算量。**

### ResNet

ResNet 核心：

> Residual Connection

```math
y=F(x)+x
```

即：

```text
       ┌──────────────┐
       │              ↓
x → Conv → Conv → Add → y
```

解决深层网络中的：

- 梯度传播困难
- 网络退化

### DenseNet

DenseNet：

> **每一层都与后续层连接。**

```math
x_l=H_l([x_0,x_1,\dots,x_{l-1}])
```

其中 $`[\cdot]`$ 表示 Concatenation。

特点：

- 特征复用
- 梯度传播好
- 参数利用率高

## 分类流程与迁移学习

### 经典 CNN 对比

| 网络      | 核心思想               |
| --------- | ---------------------- |
| LeNet     | 早期 CNN               |
| AlexNet   | 深度 CNN + ReLU + GPU  |
| VGG       | 深层 + $`3\times3`$ Conv |
| GoogLeNet | Inception，多尺度      |
| ResNet    | Residual Connection    |
| DenseNet  | Dense Connection       |

### 分类流程

```text
Image
 ↓
Preprocessing
 ↓
CNN / ViT
 ↓
Feature Extraction
 ↓
Classification Head
 ↓
Logits
 ↓
Softmax
 ↓
Class
```

### Softmax

对于类别 $`i`$：

```math
P_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
```

特点：

```math
0\le P_i\le1
```

且：

```math
\sum_iP_i=1
```

### Cross Entropy

```math
L=-\sum_i y_i\log p_i
```

如果是 one-hot label：

```math
L=-\log p_k
```

PyTorch：

```python
criterion = nn.CrossEntropyLoss()

loss = criterion(logits, labels)
```

> ⚠️ 使用 `CrossEntropyLoss` 时，通常直接输入 **logits**，不要提前手动 Softmax。

### Data Augmentation

常见增强：

- Random Crop
- Flip
- Rotation
- Resize
- Color Jitter
- Gaussian Noise

PyTorch：

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(
        brightness=0.2,
        contrast=0.2
    ),
    transforms.ToTensor()
])
```

作用：

> 增加数据多样性，提高模型泛化能力。

### Transfer Learning

迁移学习：

> **使用已经训练好的模型作为起点。**

例如：

```text
Pretrained ResNet
       ↓
Remove Original Classifier
       ↓
Replace New Classifier
       ↓
Train on New Dataset
```

### Feature Extraction

冻结 Backbone：

```python
for param in model.parameters():
    param.requires_grad = False
```

只训练新的分类头：

```python
model.fc = nn.Linear(
    model.fc.in_features,
    num_classes
)
```

### Fine-tuning

Fine-tuning：

> 在预训练模型基础上继续训练部分或全部参数。

通常：

```text
预训练模型
   ↓
较小 Learning Rate
   ↓
继续训练
   ↓
适应新数据集
```

#### Feature Extraction vs Fine-tuning

|          | Feature Extraction | Fine-tuning          |
| -------- | ------------------ | -------------------- |
| Backbone | 冻结               | 部分/全部训练        |
| 训练参数 | 少                 | 多                   |
| 计算量   | 小                 | 大                   |
| 适合     | 数据较少           | 希望进一步适应新任务 |

## 视觉 Transformer 与图文表示

### Vision Transformer

如果课程涉及：

ViT：

> 将图像划分为 Patch，把 Patch 当作 Token 输入 Transformer。

流程：

```text
Image
 ↓
Patch
 ↓
Patch Embedding
 ↓
Position Embedding
 ↓
Transformer Encoder
 ↓
Classification Head
```

Self-Attention：

```math
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
```

### Vision Transformer

ViT 核心：

> 用 Transformer 处理图像 Patch 序列。

假设图像大小：

```math
H\times W
```

Patch 大小：

```math
P\times P
```

Patch 数量：

```math
N=\frac{HW}{P^2}
```

然后：

```math
\text{Image}\rightarrow N\text{ Patches}\rightarrow N\text{ Tokens}\rightarrow\text{Transformer}
```

### CLIP

CLIP：

> Contrastive Language-Image Pre-training

核心思想：

> **同时学习图像和文本的表示，使匹配的图像-文本靠近，不匹配的远离。**

例如：

```text
Image ──→ Image Encoder ──→ Image Embedding
                                      │
                                      │ similarity
                                      ↓
Text  ──→ Text Encoder ───→ Text Embedding
```

典型应用：

- Zero-shot Classification
- Image-Text Retrieval
- 多模态理解

核心思想：

> 图像和文本进入共同的 embedding space。

资料核对日期：**2026-10-19**。下面列出值得沿着经典模型继续阅读的代表方向；编码器是否适合自己的分类任务，应通过匹配的数据划分和任务头验证。

| 模型与年份 | 核心方向 | 与分类任务的联系 | 原始资料 |

### 从模型名称回到训练范式

ResNet、ViT 主要描述网络结构；DINOv3、SigLIP 2 等还涉及预训练目标和数据方案。比较模型时，应同时记录结构、预训练方式、任务头、输入分辨率与计算预算。零样本分类、冻结特征评估和全量微调是不同的实验设置，结果应分别解释。

### 速记：CNN

>
> Conv = 特征提取
> Pooling = 下采样
> ReLU = 非线性
> FC = 分类
> BN = 稳定训练
> Dropout = 防过拟合
> Backprop = 求梯度
> Optimizer = 更新参数

### 速记：网络

>
> LeNet → 早期 CNN
> AlexNet → 深度 CNN 突破
> VGG → 小卷积堆深度
> GoogLeNet → Inception
> ResNet → Residual
> DenseNet → Dense Connection
> ViT → Patch + Transformer

### 速记：分类

>
> Logits → Softmax → Probability
> Cross Entropy → Classification Loss
> Data Augmentation → 提升泛化
> Transfer Learning → 使用预训练模型
> Fine-tuning → 继续调整预训练参数
