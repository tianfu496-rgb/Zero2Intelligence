## Softmax

对于类别 $`i`$：

$$
P_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

特点：

$$
0\le P_i\le1
$$

且：

$$
\sum_iP_i=1
$$

## Cross Entropy

$$
L=-\sum_i y_i\log p_i
$$

如果是 one-hot label：

$$
L=-\log p_k
$$

PyTorch：

```python
criterion = nn.CrossEntropyLoss()

loss = criterion(logits, labels)
```

> ⚠️ 使用 `CrossEntropyLoss` 时，通常直接输入 **logits**，不要提前手动 Softmax。

## Data Augmentation

常见增强：

- Random Crop
- Flip
- Rotation
- Resize
- Color Jitter
- Gaussian Noise

PyTorch：

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(
        brightness=0.2,
        contrast=0.2
    ),
    transforms.ToTensor()
])
```

作用：

> 增加数据多样性，提高模型泛化能力。

## Transfer Learning

迁移学习：

> **使用已经训练好的模型作为起点。**

例如：

```text
Pretrained ResNet
       ↓
Remove Original Classifier
       ↓
Replace New Classifier
       ↓
Train on New Dataset
```

## Feature Extraction

冻结 Backbone：

```python
for param in model.parameters():
    param.requires_grad = False
```

只训练新的分类头：

```python
model.fc = nn.Linear(
    model.fc.in_features,
    num_classes
)
```

## Fine-tuning

Fine-tuning：

> 在预训练模型基础上继续训练部分或全部参数。

通常：

```text
预训练模型
   ↓
较小 Learning Rate
   ↓
继续训练
   ↓
适应新数据集
```

### Feature Extraction vs Fine-tuning

|          | Feature Extraction | Fine-tuning          |
| -------- | ------------------ | -------------------- |
| Backbone | 冻结               | 部分/全部训练        |
| 训练参数 | 少                 | 多                   |
| 计算量   | 小                 | 大                   |
| 适合     | 数据较少           | 希望进一步适应新任务 |
