## 成像链路与本章目标

图像先由场景、光照、光学系统与传感器形成，再经过采样、量化和编码成为文件。影像序列还包含时间维度：视频不仅有单帧像素，也有帧率、时间戳与帧间关系。

```text
场景与光照 → 镜头投影 → 传感器响应 → 采样与量化 → 像素数组 → 编码与存储
```

阅读时同时区分三个层面：成像几何决定空间对应关系，数组表示决定模型读到的数值，文件编码决定磁盘中的字节如何还原为图像。

### 图像表示

数字图像本质上是一个二维或三维数组。

#### 灰度图

灰度图：

```math
I(x,y)\in[0,255]
```

通常：

- 0：黑色
- 255：白色
- 中间值：不同灰度

Python 中：

```python
img = cv2.imread("image.jpg", cv2.IMREAD_GRAYSCALE)
#读取图像
print(img.shape)
#输出图像尺寸 (height, width)
```

---

#### RGB 图像

RGB 图像：

```math
I(x,y)=[R(x,y),G(x,y),B(x,y)]
```

每个像素有 3 个颜色通道，分别记录红、绿、蓝的强度。

```python
img = cv2.imread("image.jpg")

print(img.shape)
# (height, width, 3)
```

> ⚠️ OpenCV 默认读取顺序是 **BGR**，不是 RGB。

转换：

```python
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
```

### 图像坐标系

通常：

```text
(0,0) ───────────→ x
  │
  │
  │
  ↓
  y
```

- 原点通常位于左上角
- x：向右增加
- y：向下增加

因此图像数组：

```python
img[y, x]
```

而不是：

```python
img[x, y]
```

> ⭐ **考试容易混淆：数学坐标通常 y 向上，而图像坐标通常 y 向下。**

### 图像采样与量化

数字化过程主要包括：

1. **采样（Sampling）**
2. **量化（Quantization）**

#### 采样

将连续空间 (x,y) 转换成离散像素位置。

决定：

> **图像空间分辨率**

采样越密集，空间分辨率越高。

#### 量化

将连续的像素强度转换为有限个离散值。

例如 8-bit：

```math
L=2^8=256
```

因此：

```math
I(x,y)\in\{0,1,\dots,255\}
```

### 分辨率

例如：

1920×1080

表示：

- 宽度：1920 pixels
- 高度：1080 pixels

总像素：

```math
1920\times1080=2{,}073{,}600
```

### 位深 Bit Depth

如果每个像素使用 bit：

```math
L=2^b
```

其中 $`L`$ 是可能的灰度级数。

| 位深   | 灰度级 |
| ------ | ------ |
| 1 bit  | 2      |
| 4 bit  | 16     |
| 8 bit  | 256    |
| 16 bit | 65536  |

> **分辨率描述空间细节，位深描述灰度/颜色精细程度。**

## 相机成像与坐标系

### 相机模型

计算机视觉中的相机模型描述：

> **三维世界如何投影到二维图像。**

基本过程：

```math
\text{3D World}\rightarrow\text{Camera}\rightarrow\text{2D Image}
```

### 针孔相机模型

三维点：

```math
P=(X,Y,Z)
```

投影：

```math
x=f\frac{X}{Z},\qquad y=f\frac{Y}{Z}
```

核心：

> **透视投影具有 $`1/Z`$ 缩放关系。**

物体越远：

```math
Z\uparrow\ \Rightarrow\ \text{投影尺寸}\downarrow
```

### 齐次坐标

二维点：

```math
(x,y)\rightarrow(x,y,1)
```

三维点：

```math
(X,Y,Z)\rightarrow(X,Y,Z,1)
```

齐次坐标可以统一表示：

- 平移
- 旋转
- 仿射变换
- 投影变换

### 相机内参

相机内参矩阵：

```math
K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}
```

其中：

- $`f_x,f_y`$：焦距
- $`c_x,c_y`$：主点

### 相机外参

外参描述：

> 世界坐标系与相机坐标系之间的关系。

```math
P_c=RP_w+t
```

其中：

- $`R`$：旋转矩阵
- $`t`$：平移向量

完整模型：

```math
s\begin{bmatrix}u\\v\\1\end{bmatrix}=K[R\mid t]\begin{bmatrix}X\\Y\\Z\\1\end{bmatrix}
```

### 内参 vs 外参

|                    | 内参              | 外参             |
| ------------------ | ----------------- | ---------------- |
| 描述               | 相机自身参数      | 相机与世界的关系 |
| 典型参数           | $`f_x,f_y,c_x,c_y`$ | $`R,t`$            |
| 是否随相机位置变化 | 通常不变          | 会变             |
| 坐标关系           | Camera 内部       | World ↔ Camera   |

## 图像、影像的表示与存储

### 数组不等于文件

| 层面 | 需要检查 | 常见问题 |
| --- | --- | --- |
| 数组形状 | 灰度 `H×W`、彩色 `H×W×C`；模型也常使用 `C×H×W` | 把宽高、通道轴弄反 |
| 数值类型 | `uint8`、`uint16`、浮点数及其有效范围 | 把高位深数据直接压成 8 位 |
| 通道语义 | RGB/BGR、透明度与灰度 | 通道顺序不一致产生偏色 |
| 空间信息 | 尺寸、像素间距、方向或地理参考信息（若数据包含） | 只保存数组而丢失坐标信息 |
| 时间信息 | 帧率、时间戳、帧顺序 | 把视频当成无序图片，或跨帧划分导致数据泄漏 |

编码文件需要解码后才能作为像素数组使用。压缩文件的大小不能直接代表图像分辨率，也不能代表解码后的内存占用。

### 格式如何选择

| 格式或容器 | 常见用途 | 学习时关注 |
| --- | --- | --- |
| JPEG | 自然照片 | 常见编码有损；反复重压缩可能改变细节 |
| PNG | 图形、透明图、离散标签 | 无损；分割标签应保持类别编号，避免插值或颜色映射改变含义 |
| TIFF / GeoTIFF | 高位深、多页或带空间信息的影像 | 检查实际编码、位深、页与元数据；不同工具支持程度不同 |
| NumPy 数组 | 保存中间张量 | 显式记录通道、范围和预处理规则 |
| MP4 等视频容器 | 带时间信息的影像 | 容器与编解码器是不同概念；读取后检查帧率和帧顺序 |

### 最小读写检查

```python
import cv2

image = cv2.imread('image.png', cv2.IMREAD_UNCHANGED)
if image is None:
    raise FileNotFoundError('image.png')

print(image.shape, image.dtype, image.min(), image.max())
if not cv2.imwrite('copy.png', image):
    raise OSError('图像保存失败')
```

读取标志、文件扩展名与所用编码器共同决定实际行为。加载后先检查数组，再做归一化或颜色转换。接口细节见 [OpenCV 图像读写文档](https://docs.opencv.org/4.x/d4/da8/group__imgcodecs.html)。

## 双目视觉与空间影像

### Stereo Vision

双目视觉使用两个相机观察同一场景。

```text
Left Camera              Right Camera
     ●------------------------●
      \                      /
       \                    /
        \        P         /
         \      / \       /
          \    /   \     /
           \  /     \   /
            \/       \ /
```

核心：

> 同一个 3D 点在左右图像中的位置不同。

### 视差

```math
d=x_L-x_R
```

视差越大：

> 物体越近。

视差越小：

> 物体越远。

### Stereo Depth

标准平行双目：

```math
Z=\frac{fB}{d}
```

其中：

- $`Z`$：深度
- $`f`$：焦距
- $`B`$：两个相机之间的基线
- $`d`$：视差

> ⭐ **这是双目视觉最重要的公式之一。**

### Epipolar Geometry

双目系统中：

> 一个相机中的点，在另一个相机中的对应点一定位于一条极线上。

对应关系：

```math
x\leftrightarrow x'
```

满足：

```math
x'^TFx=0
```

其中 $`F`$ 是 Fundamental Matrix。

### Fundamental Matrix

```math
x'^TFx=0
```

作用：

> 将二维搜索限制到一条极线。

性质：

```math
\mathrm{rank}(F)=2
```

### Essential Matrix

归一化相机坐标：

```math
x'^TEx=0
```

关系：

```math
E=K'^TFK
```

其中：

- $`F`$：像素坐标下
- $`E`$：归一化相机坐标下

Essential Matrix 可以用于恢复相对相机运动：

```math
E=[t]_\times R
```

### 三角测量

已知：

- 两台相机参数
- 同一个三维点在两个图像中的位置

可以通过两条视线求交：

```text
Camera 1
    \
     \
      \ P
       /
      /
     /
Camera 2
```

这就是：

> **Triangulation**

OpenCV：

```python
points_4d = cv2.triangulatePoints(
    P1,
    P2,
    pts1.T,
    pts2.T
)

points_3d = (
    points_4d[:3] /
    points_4d[3]
)
```

### 辨析：Sampling vs Quantization


- Sampling：空间离散化
- Quantization：数值离散化

```text
连续图像
   ↓ Sampling
离散位置
   ↓ Quantization
有限像素值
```

---

### 辨析：Homography vs Fundamental Matrix


#### Homography

```math
x'\sim Hx
```

适合：

- 平面场景
- 同一平面上的点
- 纯旋转情况下的图像关系

#### Fundamental Matrix

```math
x'^TFx=0
```

用于：

> 一般三维场景中的极几何约束。

---

### 辨析：F vs E


|              | F          | E                 |
| ------------ | ---------- | ----------------- |
| 坐标         | Pixel      | Normalized Camera |
| 是否需要内参 | 不直接需要 | 需要              |
| 极几何       | ✓          | ✓                 |
| 位姿恢复     | 间接       | ✓                 |

---

### 辨析：Intrinsic vs Extrinsic


```text
Intrinsic
= 相机自身

Extrinsic
= 相机在哪里、朝向哪里
```
