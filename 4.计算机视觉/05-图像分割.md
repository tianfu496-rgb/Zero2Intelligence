## 分割任务与输出

| 任务 | 要回答的问题 | 输出 |
| --- | --- | --- |
| 语义分割 | 每个像素是什么类别 | 像素类别图，同类实例可不区分 |
| 实例分割 | 每个独立目标占哪些像素 | 每个实例的掩码、类别等 |
| 全景分割 | 如何同时覆盖背景类别与可数实例 | 覆盖整幅图像、包含类别与实例身份的结果 |
| 提示式分割 | 用户给出的点、框或概念对应哪些区域 | 由提示条件决定的掩码；评价设置与固定类别分割不同 |

传统阈值、聚类和区域方法有助于理解分割问题；FCN、U-Net 和 Mask R-CNN 则分别引出密集预测、编码器—解码器和实例掩码分支。

## 传统分割方法

目标：

> **将图像划分成具有相似性质的区域。**

### Thresholding

最简单的分割方法：

```math
g(x,y)=\begin{cases}1,&I(x,y)>T\\0,&I(x,y)\le T\end{cases}
```

```python
_, binary = cv2.threshold(
    gray,
    127,
    255,
    cv2.THRESH_BINARY
)
```

### Otsu

Otsu 自动寻找最佳阈值。

核心：

> **最大化类间方差。**

设前景和背景分为两类：

```math
\sigma_B^2=\omega_0\omega_1(\mu_0-\mu_1)^2
```

选择使 $`\sigma_B^2`$ 最大的阈值。

OpenCV：

```python
threshold, binary = cv2.threshold(
    gray,
    0,
    255,
    cv2.THRESH_BINARY + cv2.THRESH_OTSU
)
```

优点：

> 不需要人工指定阈值。

### K-means

把像素看成数据点：

```math
x_i=[R_i,G_i,B_i]
```

目标：

```math
J=\sum_{i=1}^{N}\lVert x_i-\mu_{c_i}\rVert^2
```

流程：

```text
初始化 K 个中心
      ↓
分配样本
      ↓
重新计算中心
      ↓
重复直到收敛
```

OpenCV：

```python
data = img.reshape((-1, 3))
data = np.float32(data)

criteria = (
    cv2.TERM_CRITERIA_EPS +
    cv2.TERM_CRITERIA_MAX_ITER,
    100,
    0.2
)

K = 3

_, labels, centers = cv2.kmeans(
    data,
    K,
    None,
    criteria,
    10,
    cv2.KMEANS_RANDOM_CENTERS
)

result = centers[
    labels.flatten()
].reshape(img.shape)

result = np.uint8(result)
```

### Region Growing

区域生长：

1. 选择 Seed
2. 检查邻域
3. 如果相似，则加入区域
4. 从新像素继续生长

```text
Seed
 ↓
检查邻居
 ↓
相似？
 ├── Yes → 加入区域
 └── No  → 忽略
```

优点：

> 能利用空间连通性。

缺点：

- 依赖 Seed
- 对阈值敏感
- 噪声可能影响生长

### Watershed

Watershed 将图像看成地形：

```text
山峰
  ▲
 / \
/   \
     \____
      水域
```

不同区域逐渐“灌水”，相遇的位置形成分界线。

常用于：

> **粘连目标分离。**

OpenCV 基本流程：

```python
# markers 是预先定义的区域标记
markers = np.int32(markers)

cv2.watershed(
    img,
    markers
)
```

## 深度分割模型

### Semantic Segmentation

目标：

> **给每个像素分配一个类别。**

例如：

```text
Pixel → road
Pixel → car
Pixel → person
Pixel → sky
```

注意：

同类别不同实例通常不区分。

### Semantic Segmentation

目标：

> 每一个像素预测一个类别。

典型模型：

- FCN
- U-Net
- DeepLab

输出：

```math
H\times W\times C
```

每个像素都有 $`C`$ 个类别的预测。

### FCN

FCN：

> Fully Convolutional Network

核心思想：

> **将传统 CNN 中的全连接层替换为卷积结构，使网络能够输出空间特征图。**

流程：

```text
Image
 ↓
CNN
 ↓
Feature Map
 ↓
Upsampling
 ↓
Pixel-wise Prediction
```

核心贡献：

> 将 CNN 从图像级分类扩展到像素级预测。

### U-Net

U-Net 采用：

> **Encoder-Decoder + Skip Connection**

结构：

```text
Encoder                  Decoder

Image
 ↓                         ↑
Conv                      Conv
 ↓                         ↑
Conv                      Conv
 ↓                         ↑
Bottleneck ─────────────→
```

Skip Connection 将 Encoder 的高分辨率特征传给 Decoder。

优势：

> 保留细节信息，适合医学图像分割等像素级任务。

### Instance Segmentation

Instance Segmentation：

> 不仅预测类别，还区分同类别的不同实例。

例如：

```text
两只猫

Semantic:
cat cat cat cat

Instance:
cat_1 cat_1
cat_2 cat_2
```

### Instance Segmentation

目标：

> 同时完成 Detection + Pixel-level Mask。

典型模型：

> Mask R-CNN

### Mask R-CNN

Mask R-CNN 可以理解为：

> Faster R-CNN + Mask Branch

结构：

```text
Image
 ↓
Backbone
 ↓
RPN
 ↓
RoI
 ├── Classification
 ├── Bounding Box
 └── Mask
```

因此每个目标得到：

- 类别
- Bounding Box
- Pixel Mask

SAM 系列的提示式能力与固定类别语义分割模型有不同的输入、输出和评价条件。选择模型前，先明确任务是“给整幅图像逐像素分类”，还是“根据提示找出对象并跟踪”。

## 分割的损失与评价

像素分类可以使用交叉熵；类别不均衡时也常结合 Dice 等重叠度目标。下面用二值前景集合 $`A`$、$`B`$ 表示预测与标注：

```math
\mathrm{IoU}(A,B)=\frac{\lvert A\cap B\rvert}{\lvert A\cup B\rvert}
```

```math
\mathrm{Dice}(A,B)=\frac{2\lvert A\cap B\rvert}{\lvert A\rvert+\lvert B\rvert}
```

空集合、忽略标签、背景是否参与平均以及逐图/逐类平均方式应按评估协议明确。语义分割常看每类 IoU 与 mIoU，实例分割可看 mask AP，全景分割使用的协议又不同。

## 速查、比较与实践

### 对比：分割


| 方法                  | 类型        | 核心         |
| --------------------- | ----------- | ------------ |
| Threshold             | 无监督/规则 | 像素阈值     |
| Otsu                  | 自动阈值    | 最大类间方差 |
| Region Growing        | 区域        | 邻域相似性   |
| K-means               | 聚类        | 距离         |
| Watershed             | 区域        | 地形/分水岭  |
| Semantic Segmentation | 深度学习    | 像素类别     |
| Instance Segmentation | 深度学习    | 像素 + 实例  |

> 同类别也区分不同目标。
