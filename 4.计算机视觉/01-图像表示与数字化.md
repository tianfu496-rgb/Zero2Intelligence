## 图像表示

数字图像本质上是一个二维或三维数组。

### 灰度图

灰度图：

```math
I(x,y)\in[0,255]
```

通常：

- 0：黑色
- 255：白色
- 中间值：不同灰度

Python 中：

```python
img = cv2.imread("image.jpg", cv2.IMREAD_GRAYSCALE)
#读取图像
print(img.shape)
#输出图像尺寸 (height, width)
```

---

### RGB 图像

RGB 图像：

```math
I(x,y)=[R(x,y),G(x,y),B(x,y)]
```

每个像素有 3 个颜色通道，分别记录红、绿、蓝的强度。

```python
img = cv2.imread("image.jpg")

print(img.shape)
# (height, width, 3)
```

> ⚠️ OpenCV 默认读取顺序是 **BGR**，不是 RGB。

转换：

```python
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
```

## 图像坐标系

通常：

```text
(0,0) ───────────→ x
  │
  │
  │
  ↓
  y
```

- 原点通常位于左上角
- x：向右增加
- y：向下增加

因此图像数组：

```python
img[y, x]
```

而不是：

```python
img[x, y]
```

> ⭐ **考试容易混淆：数学坐标通常 y 向上，而图像坐标通常 y 向下。**

## 图像采样与量化

数字化过程主要包括：

1. **采样（Sampling）**
2. **量化（Quantization）**

### 采样

将连续空间 (x,y) 转换成离散像素位置。

决定：

> **图像空间分辨率**

采样越密集，空间分辨率越高。

### 量化

将连续的像素强度转换为有限个离散值。

例如 8-bit：

```math
L=2^8=256
```

因此：

```math
I(x,y)\in\{0,1,\dots,255\}
```

## 分辨率

例如：

1920×1080

表示：

- 宽度：1920 pixels
- 高度：1080 pixels

总像素：

```math
1920\times1080=2{,}073{,}600
```

## 位深 Bit Depth

如果每个像素使用 bit：

```math
L=2^b
```

其中 $`L`$ 是可能的灰度级数。

| 位深   | 灰度级 |
| ------ | ------ |
| 1 bit  | 2      |
| 4 bit  | 16     |
| 8 bit  | 256    |
| 16 bit | 65536  |

> **分辨率描述空间细节，位深描述灰度/颜色精细程度。**
