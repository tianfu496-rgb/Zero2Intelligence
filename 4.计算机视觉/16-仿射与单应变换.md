> 几何视觉 · 仿射、Homography 与透视变换

## Homography

两个图像之间：

```math
x'\sim Hx
```

其中：

```math
H\in\mathbb{R}^{3\times3}
```

由于整体尺度不影响结果：

> $`H`$ 有 **8 个自由度**。

因此至少需要：

> **4 对不共线点。**

OpenCV：

```python
H, mask = cv2.findHomography(
    pts1,
    pts2,
    cv2.RANSAC
)
```

应用：

- 图像拼接
- 文档矫正
- 平面目标跟踪
- 透视变换

## 仿射变换

二维仿射变换：

```math
\begin{bmatrix}x'\\y'\end{bmatrix}=A\begin{bmatrix}x\\y\end{bmatrix}+t
```

齐次形式：

```math
\begin{bmatrix}x'\\y'\\1\end{bmatrix}=\begin{bmatrix}a&b&t_x\\c&d&t_y\\0&0&1\end{bmatrix}\begin{bmatrix}x\\y\\1\end{bmatrix}
```

可以表示：

- 平移
- 旋转
- 缩放
- 剪切

至少需要：

> **3 对不共线点。**

## 透视变换

Perspective Transformation：

```math
x'\sim Hx
```

与仿射变换相比：

> 透视变换能够描述更一般的投影关系。

例如：

```text
现实中的矩形
      ↓
相机拍摄
      ↓
梯形
```

OpenCV：

```python
result = cv2.warpPerspective(
    img,
    H,
    (width, height)
)
```
