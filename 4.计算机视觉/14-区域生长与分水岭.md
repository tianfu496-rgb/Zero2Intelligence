## Region Growing

区域生长：

1. 选择 Seed
2. 检查邻域
3. 如果相似，则加入区域
4. 从新像素继续生长

```text
Seed
 ↓
检查邻居
 ↓
相似？
 ├── Yes → 加入区域
 └── No  → 忽略
```

优点：

> 能利用空间连通性。

缺点：

- 依赖 Seed
- 对阈值敏感
- 噪声可能影响生长

## Watershed

Watershed 将图像看成地形：

```text
山峰
  ▲
 / \
/   \
     \____
      水域
```

不同区域逐渐“灌水”，相遇的位置形成分界线。

常用于：

> **粘连目标分离。**

OpenCV 基本流程：

```python
# markers 是预先定义的区域标记
markers = np.int32(markers)

cv2.watershed(
    img,
    markers
)
```
