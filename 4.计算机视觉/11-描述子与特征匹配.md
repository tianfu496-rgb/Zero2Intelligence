## 特征描述子

特征检测回答：

> **哪里有特征？**

描述子回答：

> **这个特征长什么样？**

例如：

```text
Keypoint Detection
       ↓
找到关键点位置
       ↓
Descriptor
       ↓
描述关键点附近区域
       ↓
Feature Matching
```

## 特征匹配

### BFMatcher

SIFT 等浮点描述子通常使用：

L2L_2

ORB 等二进制描述子通常使用：

> Hamming Distance

```python
bf = cv2.BFMatcher(
    cv2.NORM_HAMMING,
    crossCheck=True
)

matches = bf.match(
    descriptors1,
    descriptors2
)

matches = sorted(
    matches,
    key=lambda x: x.distance
)
```

---

### SIFT + Ratio Test

```python
bf = cv2.BFMatcher()

matches = bf.knnMatch(
    des1,
    des2,
    k=2
)

good = []

for m, n in matches:
    if m.distance < 0.75 * n.distance:
        good.append(m)
```

### 为什么需要 Ratio Test？

如果：

```math
\frac{d_1}{d_2}
```

很小：

> 最近邻明显比第二近邻更相似 → 匹配更可靠。
