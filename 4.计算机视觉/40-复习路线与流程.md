## 最终考前速记版

> ### 图像
>
> Sampling = 空间离散
> Quantization = 数值离散
> Histogram = 灰度分布
> Equalization = 增强对比度

> ### 滤波
>
> Mean = 平均
> Gaussian = 加权平均
> Median = 去椒盐
> Sobel = 一阶导数
> Laplacian = 二阶导数
> Canny = 多阶段边缘检测

> ### 特征
>
> Harris = Corner
> SIFT = Scale + Rotation Invariant
> ORB = FAST + BRIEF
> Descriptor = 描述特征
> Matching = 找对应关系
> RANSAC = 去除外点

> ### 几何
>
> Camera = 3D → 2D
> Intrinsic = $`K`$
> Extrinsic = $`R,t`$
> Homography = 平面关系
> F = Epipolar Geometry
> E = Normalized Camera Geometry
> Stereo = Disparity → Depth
> Triangulation = 多视图 → 3D

> ### 检测
>
> IoU = 框重叠程度
> NMS = 去重复框
> Precision = 预测出来的有多少是真的
> Recall = 真的有多少被找到
> AP = 单类别 PR 曲线指标
> mAP = 多类别 AP 的平均

> ### CNN
>
> Conv = 特征提取
> Pooling = 下采样
> ReLU = 非线性
> FC = 分类
> BN = 稳定训练
> Dropout = 防过拟合
> Backprop = 求梯度
> Optimizer = 更新参数

> ### 网络
>
> LeNet → 早期 CNN
> AlexNet → 深度 CNN 突破
> VGG → 小卷积堆深度
> GoogLeNet → Inception
> ResNet → Residual
> DenseNet → Dense Connection
> ViT → Patch + Transformer

> ### 分类
>
> Logits → Softmax → Probability
> Cross Entropy → Classification Loss
> Data Augmentation → 提升泛化
> Transfer Learning → 使用预训练模型
> Fine-tuning → 继续调整预训练参数

> ### 现代 CV
>
> FCN → 全卷积分割
> U-Net → Encoder-Decoder + Skip Connection
> Mask R-CNN → Detection + Instance Mask
> ViT → Transformer for Vision
> CLIP → Image-Text Alignment
> Diffusion → Noise → Image
