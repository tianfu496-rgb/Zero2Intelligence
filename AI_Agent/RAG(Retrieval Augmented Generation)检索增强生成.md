# RAG：检索增强生成

[← Agent 主题目录](README.md) · [系统学习：记忆与检索增强](05-记忆与检索增强.md)

RAG（Retrieval-Augmented Generation）先检索相关资料，再将资料与问题一同交给生成模型，帮助回答有依据的问题。

## 工作流程

1. **准备知识库**
   - **分片**：将原始文档切成便于检索的片段。
   - **向量化与索引**：用 Embedding 模型把片段转换为向量，将文本、向量及来源信息存入检索系统。
2. **处理用户问题**
   - **召回**：使用同一套向量化方法表示问题，检索候选片段。常见相似度包括余弦相似度、欧氏距离与点积。
   - **重排**：对候选片段再次排序，挑选与问题最相关的内容。召回侧重覆盖，重排侧重排序质量。
3. **生成回答**：将问题和选中的片段组织成提示词，让模型据此回答；需要可追溯性时附上片段来源。
